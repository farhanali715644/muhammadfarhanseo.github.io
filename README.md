# Muhammad Farhan | SEO Executive Portfolio

Responsive, static portfolio website using HTML, CSS and JavaScript. No build tools required.

## Files
- `index.html`: All website content and sections
- `style.css`: Styling and responsive layouts
- `script.js`: Mobile menu, animations and copyright year

## GitHub Pages setup
1. Sign in to https://github.com and note your exact username.
2. Create a **public** repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your actual GitHub username).
3. Upload `index.html`, `style.css`, and `script.js` into the repository **root**, not a subfolder. Commit the changes.
4. Visit **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Visit `https://YOURUSERNAME.github.io/` once GitHub Pages has published your files.

## Personalization
- Replace the initials-only avatar in `index.html` with a photo when ready. For example, insert `<img src="profile.jpg" alt="Muhammad Farhan" />` into the `.avatar` element, and add `.avatar img{width:100%;height:100%;object-fit:cover}` to `style.css`. Upload `profile.jpg` beside `index.html`.
- Add verified projects/results later if you want a Case Studies section. No unverified numerical results have been included.
- Change any text, phone/email/LinkedIn link in `index.html`.

## Notes
- Google Fonts are used online; the site displays system fallbacks if they are unavailable.
- The email opens an email application, and phone opens your dialer on supported devices. There is no backend/contact form.
- All content is based on information provided by Muhammad Farhan, with general descriptions of SEO work not independently verified.
